## 1. CNA（相干噪声抑制指标）

协议定义：`CNA = 10*log10( ||nc||^2 / ||P_C(y - s)||^2 )`，越高越好。
`nc` 为已知注入的相干噪声；`P_C` 为向**预由注入线性干扰与频散面波模板构成之子空间**的
最小二乘投影。

### 1.1 ⚠️ 论文级声明义务（A1，**按 R16-d 改写后的文字**，不得改写）

> CNA 为**注入基目标型**指标：其子空间由**注入所用的分量基**构成，
> 衡量对**该注入成分**的抑制；**不代表对任意相干噪声的普适评价**。

**补充事实（R16-d 要求写明）**：子空间与注入参数**同源**——这正是该指标的定义方式，
**不是缺陷**；但正因如此，**不得据此推断方法对未见噪声的泛化能力**。

**判据失效的边界（如实声明）**：若子空间未能精确张成注入家族，则投影回收不足 →
所有方法的 CNA 趋于 0 dB → CNA 失去区分度，依赖它的三态判据（A 的 −0.5 dB、
C 的 >1 dB）将立于死指标上。故**先决门禁（§1.4）必须按非退化口径执行**。

### 1.2 子空间构造（A1 要求：写明方式 + 秩/截断规则）

* **构造方式（R16-a：分量基精确张成，禁用抽样建基）**：
  由生成器**导出注入所用的分量基**，子空间直接由该基构造：

  1. **线性干扰**：`linear_coherent_basis(v_app, dt, dx, ns, ntr, f_main)`
     —— 家族唯一随机量是整体幅度 ⇒ 每组 `(v_app, f_main)` **1 维**；
     覆盖注册的 `v_app ∈ {800,1500,3000} × f_main ∈ {15,25,40}`，
     并另加注入实际使用的那一组。
  2. **频散面波**：`dispersion_component_basis(...)`
     —— 由 `A_i·sin(2πf_iτ_i + φ_i) = (A_i cos φ_i)·sin(2πf_iτ_i) + (A_i sin φ_i)·cos(2πf_iτ_i)`
     可知**每分量 2 维**（sin/cos）⇒ 共 **2·n_components 维**；
     频率轴规则与注入实现**完全一致**（`np.linspace(f_lo, f_hi, n_components)`）。
  3. 将基按列展平为 `T`（`n_features × n_basis`），对 `T` 做 SVD，
     保留奇异值 ≥ `rank_tol·σ_max` 的左奇异向量 `U`（**列空间由 `U` 给出**）构成正交基 `Q`；
  4. 投影 `P_C(v) = Q Qᵀ v`。
  5. **禁用**"抽 N 个随机实现建基"——实测不收敛（见 §1.4 对照）。
* **秩/截断规则**：`rank_tol`（奇异值相对阈值）为**冻结参数**；
  P1.2 给出**候选值** `1e-8`（几乎不截断，保留全部数值可分辨方向），
  **语义**：保留所有能量占比 ≥ `rank_tol` 的方向；**P1.5 冻结**。
* **模板成分约束（A1-2）**：模板**只含相干噪声成分**，**不含**随机噪声或真值信号。
* **与方法输出无关（A1-1）**：模板参数只来自冻结配置；子空间构造
  **不得读取任何方法输出或结果文件**——由 `test_metrics_independence.py` 的机械检查保证。

### 1.4 先决门禁（**R16-b：非退化口径**）

**协议硬门禁**：先用纯相干噪声验证投影回收误差 ≤ **5%**。
回收误差定义：`||P_C(nc) − nc|| / ||nc||`。

**门禁数据必须为独立新实现**（新建随机源，**不得**是建基所用的任何实现），
按三族分报，并**同时给出"精确模板"的退化对照**：

| 类别 | 门禁判据 | 2026-09-25 实测（分量基） |
| :--- | :--- | :--- |
| 线性干扰（独立新实现） | ≤5% | **1.389e-15**（最大，10 个实现） |
| 频散面波（独立新实现） | ≤5% | **2.075e-15** |
| 混合（相干+相干） | ≤5% | **2.115e-15** |
| 退化对照（精确模板回投） | — | 6.088e-16 / 1.301e-15 |

> **整改前后对照（面波家族，独立新实现回收误差中位）**：
> 抽样建基 k=1 → 98.93%；k=5 → 86.54%；k=20 → 50.98%；k=40 → 0.06%；
> **分量基（48 维）→ 1.735e-15**。
> 故**抽样建基在本项目禁用**。

> **"相干 + 随机"混合档**：随机成分**本不属**相干子空间，其回收误差反映随机成分占比
> （实测中位 9.2%），**不是**实现缺陷，也**不**用于 5% 门禁。

### 1.3 边界情形（沿用 P0.3-Am3 C1–C6 的同类约定）

| 情形 | 约定返回值 | 依据 |
| :--- | :--- | :--- |
| `y = s`（完全去噪） | `P_C(0) = 0` → CNA = **`+inf`**（置哨兵标志），不返回 NaN | 同 C1 |
| `y = x`（不处理） | 返回有限值，量级与"未抑制相干噪声"一致 | 本单新增 |
| 残差能量为 0 且 `nc` 能量为 0 | `ValueError`（配置错误） | 同 C2 精神 |

## 1.5 裁定 D（预注册）· 事件匹配器的证据等级

> **本节为预注册的「证据等级」类条款，P1.5 冻结后不得事后更改。**

1. **核心事件证据固定为真值窗指标**（包络峰值到时绝对误差 + 归一化窗能量误差）——
   与协议一致，且**与匹配器表现无关**。
2. **复杂逐事件匹配指标一律列为辅助证据**（**无条件**，无论在构造测试集上是否 ≥95%）。
   理由：匹配器的**实际操作对象是去噪输出（含残余噪声与伪影）**，而非无噪测试集；
   以无噪 1.0 论证"95% 门限已达成"属**越界声称**。
3. 论文中若报告匹配率，**必须同时标注条件**（无噪 / 含噪档位），不得只报无噪那一栏。
4. 本节三条**列入 P1.5 冻结清单**。

## 2. 事件级指标

* **到时误差**：对 `y` 与 `s` 各取 Hilbert 解析信号包络，在**真值事件窗**内取包络峰值位置，
  二者之差取绝对值，单位 **ms**。多事件时逐事件给出，报告**中位数与最大值**。
* **归一化窗内能量误差**：`|E_y − E_s| / E_s`（窗内能量），逐事件给出，报告**中位与最大**。
* **事件窗来源**：沿用**已冻结**掩码规则（沿时间轴膨胀 `n_T`、round-half-up）；
  **本单不修改该规则**。
* **事件表**：本单以**草案**形式给出（`configs/event_table_draft.yaml`），**P1.5 冻结**。

## 3. 事件匹配器 —— 容差先冻结、后测量（A2）

> **冻结声明**：下表容差在**运行匹配器测量匹配率之前**写入本文件并冻结。
> 若开发过程中调整过容差，须在 `docs/execution-log.md` 如实报告**调整序列与每次匹配率**，
> 并给出最终冻结值（P1.5）。**不得**只报最终一次的结果。

### 3.1 容差声明（测量前冻结，2026-09-25）

| 参数 | 值 | 语义 |
| :--- | :--- | :--- |
| `time_tol_ms` | **40.0** | 检出事件与真值事件的到时差 ≤ 该值视为时间上可匹配 |
| `trace_tol` | **2** | 道号差 ≤ 该值视为空间上可匹配 |
| `allow_one_to_many` | **false** | 不允许一对多（严格：每个检出最多配一个真值，反之亦然） |
| `matching_rule` | **greedy-nearest** | 按到时差升序贪心配对；已配对者不再参与 |

**容差取值依据（先声明）**：`time_tol_ms = 40 ms` ≈ 本项目主频下界 15 Hz 的约 0.6 个周期，
足以容纳包络峰值的采样/插值抖动，又不足以混淆**分离度 ≥ 80 ms** 的相邻事件；
`trace_tol = 2` 道 ≈ 20 m（`dx=10 m`），容纳事件横向位置的量化误差。

### 3.2 测试集（由构造定义真值）

测试集为**人工构造**，事件位置/数量/分离度**生成时显式给定**（非"检测后标定"）。
三类子集：

| 子集 | 构造 | 目的 |
| :--- | :--- | :--- |
| `isolated` | 单事件或间距 > 200 ms | 基线 |
| `near_neighbor` | 相邻事件间距 40–120 ms | 近邻困难情形 |
| `partial_overlap` | 相邻事件间距 < 40 ms（时间上部分重叠） | 重叠困难情形 |

### 3.3 报告口径（A2 要求）

* 同时报告 **精确率 Precision / 召回率 Recall / F1**；
* **"正确匹配率"定义**：本单采用 **F1** 作为"正确匹配率"的判据口径
  （理由：门限 95% 须同时约束误配与漏配，单看精确率或召回率均可被单侧操纵）；
* 逐子集报告，并给出总体；
* **未达 95%** → 复杂逐事件匹配**降级为辅助指标**（协议规定路径），
  核心事件证据**固定使用真值窗的到时与能量误差**；**不放宽门限**。

### 3.4 验证集的噪声条件与适用范围（**L1：不得过度声称**）

**验证集噪声条件（如实声明）**：3.2 节三个子集的**初版**匹配率（F1=1.0）取自
**无噪条件**（检出事件由构造直接给定，未叠加随机噪声或去噪残余）。

**补充验证（本单新增，2026-09-25 实测）**：在**注册噪声档 L2**
（口径 ii 振幅比例 **0.60**；该档实测输入 SNR = **4.44 dB**）下增补一组匹配率：

| 子集 | 无噪 F1 | **L2（含噪）F1** | L2 精确率 | L2 召回率 |
| :--- | ---: | ---: | ---: | ---: |
| `isolated` | 1.000 | **0.800** | 0.667 | 1.000 |
| `near_neighbor` | 1.000 | **0.727** | 0.571 | 1.000 |
| `partial_overlap` | 1.000 | **0.667** | 0.500 | 1.000 |
| 三子集平均 | **1.000** | **0.731** | — | — |

**关键观察**：含噪条件下**召回率恒为 1.0**（不漏检），**精确率下降**
（噪声产生额外误检）⇒ F1 从 1.000 降至 **0.731**，**低于 95% 门限**。

**适用范围（论文表述边界，L1 要求）**：
本 95% 门限的**适用范围为无噪（或低噪）条件**。
在注册档 L2（实测 4.44 dB）下匹配率 **0.731 < 0.95**，
故论文中**不得**表述为"匹配器在噪声数据上仍可达 95%"；
复杂逐事件匹配的适用性须按**实测条件**限定表述
（协议规定的降级路径在此条件下即被触发）。

**注（如实记录）**：口径 (ii) 振幅比例 0.60 对应实测 SNR **4.44 dB**，
与口径 (i) 的名义目标 0 dB **并不精确对齐**；两口径的标定关系须在 **P1.5 冻结**时明确。

## 5. 噪声强度：两个口径的定义与关系（裁定 E，预注册）

> **P1.5 冻结后不得事后更改。**

### 5.1 口径定义

| 口径 | 名称 | 角色 | 用途 |
| :--- | :--- | :--- | :--- |
| **(i)** | `target_input_snr_db` | **规范口径（normative）** | 对外报告与三态判定以此为准；协议首要质量指标即以 SNR 表达 |
| **(ii)** | `amplitude_ratio` | **描述性口径（descriptive）** | 仅用于生成实现；不作为对外声明 |

**硬要求**：每个观测的**实测输入 SNR 必须逐个记录并报告**，**不得按名义值假定**。

映射按**实测冻结**，**不得强行统一为单一映射**；

### 5.4 三条实测发现（如实并列，不强行统一）

1. **N1 与 N3**：两模型映射**完全一致**（差 0.00 dB）——因为二者均按干净数据 RMS 归一化，
   输入 SNR 由 `amplitude_ratio` **唯一决定**（`SNR = −20·log10(ratio)`：
   0.30→10.46、0.60→4.44、1.00→0.00）。
2. **N2（线性相干干扰）口径 (ii) 不适用**：`add_linear_coherent` 的幅度由内部随机源给出
   （`uniform(0.5, 1.5)`），**不接受 `amplitude_ratio` 参数**；故 N2 的三个档位实测 SNR
   **完全相同**（M1 均 11.12 dB；M2 均 13.90 dB）。
   → **N2 的档位须以口径 (i) 直接指定**，不能经 amplitude_ratio 表达。
3. **N2 下模型差异显著**：M1 **11.12 dB** vs M2 **13.90 dB**，相差 **2.78 dB**
   ⇒ 映射**不统一**，按裁定 E **如实并列**。

### 5.5 待 P1.5 解决的两项

1. **N2 的档位定义**：需改为按目标输入 SNR 直接生成（例如缩放干扰幅度以命中目标 SNR），
   或明确声明 N2 不参与三档强度设计。
2. **标定表的最终冻结**：本表为草案；P1.5 冻结时须复核并补齐（若 N2 改为 SNR 目标式）。

## 6. 裁定 F（预注册）· 零/少事件面板的确定性回退阶梯

**问题**：FP3 在冻结阈值 `k_mad = 3.0` 下检出 **0** 个事件窗；而野外四项指标中的
"振幅保持（预选事件窗内稳健包络 RMS）"与"同相轴连续性"**都依赖事件窗** ——
零事件面板会在 9 个预注册设置里产生**空单元格**。

**裁定（事前声明、机械、统一、留痕）**：

1. **保留已选定的 top-3 面板**（排序在测量前冻结，**不得**因零事件换成 #4）。
2. **确定性回退阶梯**：若某面板在 `k_mad = 3.0` 下事件窗数 **< 2**，则按序尝试
   `k_mad ∈ {2.5, 2.0, 1.5}`，取**第一个**给出 ≥2 个事件窗的 k；
   若直至 `1.5` 仍 <2，则该面板**事件窗相关指标记为 N/A**（并写明原因）。
3. **逐面板记录实际使用的 `k_mad`**，随 P1.5 冻结。
4. 论文须披露：该回退规则为**事前声明**，且各面板实际取值不同。

**实测结果（2026-09-25）**

| 面板 | k_mad=3.0 | 2.5 | 2.0 | 1.5 | **采用** |
| :--- | ---: | ---: | ---: | ---: | ---: |
| FP1 | 1 | 1 | 1 | **2** | **1.5** |
| FP2 | **3** | — | — | — | **3.0** |
| FP3 | 0 | **3** | — | — | **2.5** |

→ 三个面板均达到 ≥2 窗，**无面板需记 N/A**。

## 7. 裁定 G · P2 判据修正（**已解耦；最终裁定：P2 不参与面板质量判据**）

### 7.1 原判据（作废）
`outlier_trace_fraction < 0.05`：40 个候选 **0/40 满足**（实测 0.0595–0.5165）；
`dead_trace_fraction` **40/40 满足**（max 0.0010）—— 两者均无区分力，**P2 未参与 P1.3 排序**。

### 7.2 第一代替代口径（**已撤回：自证**）
曾把阈值改为「全候选逐道值的 **P5 = −0.4108**」，判据仍为「比例 < 0.05」。
**缺陷**：阈值取自**同一分布的分位数**，而判据比较的正是该分布下的比例 ⇒
按构造任一候选约有 5% 的取值落在阈值以下 ⇒ 判据恒落在临界线上 ⇒ **自证**，
与 P1.2 的判据缺陷**同类**。（签发方 P1.3-Am2 第三节指出，本执行方接受。）

### 7.4 根因（**新发现，决定性**）
相邻道零延迟相关系数在本数据集上**整体接近 0**：FP1 逐道值**中位仅 0.0575**。
SEG-Y 头段实测（`mv1001shots_subset8000.sgy`）：总道数 8000；
`FieldRecord`（炮号）唯一值 **41**；`TraceNumber`（道号）唯一值 **199**；`SortingCode = 6`。
即道轴 = **约 41 个炮记录 × 约 199 道**，相邻道**绝大多数是同一炮内的相邻接收道**
（跨炮边界仅约 40/7999 ≈ 0.5%）⇒ 近零相关**不是**跨炮拼接造成，而是**数据本身**如此。
因此「相邻道相关系数低于阈值」在本数据上**不表达几何质量**，语义未被建立。
