## 1. CNA（相干噪声抑制指标）

协议定义：`CNA = 10*log10( ||nc||^2 / ||P_C(y - s)||^2 )`，越高越好。
`nc` 为已知注入的相干噪声；`P_C` 为向**预由注入线性干扰与频散面波模板构成之子空间**的
最小二乘投影。

### 1.1 ⚠️ 论文级声明义务（A1，照抄归档件文字，不得改写）

> CNA 为**模板目标型**指标：其子空间由注入的线性干扰与频散面波模板构成，
> 因此它**衡量的是对已知相干噪声族的抑制**，不构成对任意相干噪声的普适评价。

**含义（补充说明，非替代上句）**：方法若恰好贴合该子空间，即可获得较高的 CNA；
本指标**不试图**评价对未知/未建模相干噪声的抑制能力。

### 1.2 子空间构造（A1 要求：写明方式 + 秩/截断规则）

* **构造方式**：模板 Gram 矩阵 + SVD 截断（正交基构造）。
  1. 由**冻结配置**给出的模板参数生成若干相干噪声模板（线性干扰 + 频散面波）；
  2. 将各模板按列展平为矩阵 `T`（形状 `n_features × n_templates`）；
  3. 对 `T` 做 SVD，取奇异值比 ≥ `rank_tol` 的右奇异向量构成正交基 `Q`；
  4. 投影 `P_C(v) = Q Qᵀ v`。
* **秩/截断规则**：`rank_tol`（奇异值相对阈值）为**冻结参数**；
  P1.2 给出**候选值** `1e-8`（几乎不截断，保留全部数值可分辨方向），
  **语义**：保留所有能量占比 ≥ `rank_tol` 的方向；**P1.5 冻结**。
* **模板成分约束（A1-2）**：模板**只含相干噪声成分**，**不含**随机噪声或真值信号。
* **与方法输出无关（A1-1）**：模板参数只来自冻结配置；子空间构造
  **不得读取任何方法输出或结果文件**——由 `test_metrics_independence.py` 的机械检查保证。

### 1.3 边界情形（沿用 P0.3-Am3 C1–C6 的同类约定）

| 情形 | 约定返回值 | 依据 |
| :--- | :--- | :--- |
| `y = s`（完全去噪） | `P_C(0) = 0` → CNA = **`+inf`**（置哨兵标志），不返回 NaN | 同 C1 |
| `y = x`（不处理） | 返回有限值，量级与"未抑制相干噪声"一致 | 本单新增 |
| 残差能量为 0 且 `nc` 能量为 0 | `ValueError`（配置错误） | 同 C2 精神 |

## 2. 事件级指标

* **到时误差**：对 `y` 与 `s` 各取 Hilbert 解析信号包络，在**真值事件窗**内取包络峰值位置，
  二者之差取绝对值，单位 **ms**。多事件时逐事件给出，报告**中位数与最大值**。
* **归一化窗内能量误差**：`|E_y − E_s| / E_s`（窗内能量），逐事件给出，报告**中位与最大**。
* **事件窗来源**：沿用**已冻结**掩码规则（沿时间轴膨胀 `n_T`、round-half-up）；
  **本单不修改该规则**。
* **事件表**：本单以**草案**形式给出（`configs/event_table_draft.yaml`），**P1.5 冻结**。

## 3. 事件匹配器 —— 容差先冻结、后测量（A2）

> **冻结声明**：下表容差在**运行匹配器测量匹配率之前**写入本文件并冻结。
> 若开发过程中调整过容差，须在 `docs/execution-log.md` 如实报告**调整序列与每次匹配率**，
> 并给出最终冻结值（P1.5）。**不得**只报最终一次的结果。

### 3.1 容差声明（测量前冻结，2026-09-25）

| 参数 | 值 | 语义 |
| :--- | :--- | :--- |
| `time_tol_ms` | **40.0** | 检出事件与真值事件的到时差 ≤ 该值视为时间上可匹配 |
| `trace_tol` | **2** | 道号差 ≤ 该值视为空间上可匹配 |
| `allow_one_to_many` | **false** | 不允许一对多（严格：每个检出最多配一个真值，反之亦然） |
| `matching_rule` | **greedy-nearest** | 按到时差升序贪心配对；已配对者不再参与 |

**容差取值依据（先声明）**：`time_tol_ms = 40 ms` ≈ 本项目主频下界 15 Hz 的约 0.6 个周期，
足以容纳包络峰值的采样/插值抖动，又不足以混淆**分离度 ≥ 80 ms** 的相邻事件；
`trace_tol = 2` 道 ≈ 20 m（`dx=10 m`），容纳事件横向位置的量化误差。

### 3.2 测试集（由构造定义真值）

测试集为**人工构造**，事件位置/数量/分离度**生成时显式给定**（非"检测后标定"）。
三类子集：

| 子集 | 构造 | 目的 |
| :--- | :--- | :--- |
| `isolated` | 单事件或间距 > 200 ms | 基线 |
| `near_neighbor` | 相邻事件间距 40–120 ms | 近邻困难情形 |
| `partial_overlap` | 相邻事件间距 < 40 ms（时间上部分重叠） | 重叠困难情形 |

### 3.3 报告口径（A2 要求）

* 同时报告 **精确率 Precision / 召回率 Recall / F1**；
* **"正确匹配率"定义**：本单采用 **F1** 作为"正确匹配率"的判据口径
  （理由：门限 95% 须同时约束误配与漏配，单看精确率或召回率均可被单侧操纵）；
* 逐子集报告，并给出总体；
* **未达 95%** → 复杂逐事件匹配**降级为辅助指标**（协议规定路径），
  核心事件证据**固定使用真值窗的到时与能量误差**；**不放宽门限**。

## 4. 作用域声明（A3）

* **CNA 与事件级指标须在两个合成模型（M1 水平层状 / M2 含倾斜-弯曲-断层）上均可计算**。
* 本批（P1.2）验收覆盖：**见 `docs/execution-log.md` 的实测记录**；
  若某模型仅做了可用性验证而未做完整数值验收，须在此**明确声明作用域**，
  并把该模型的完整覆盖**列入 P1.5 冻结清单**。
* **独立性守卫**：`tests/test_metrics_independence.py` 断言指标实现
  **不导入** `bench.methods` / `bench.fusion` / 任何 `coherence` 相关模块——
  即指标不依赖被评对象。
