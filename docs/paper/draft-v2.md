## 摘要

地震数据去噪方法繁多，但**跨方法可比性**长期缺失：各方法在不同数据、不同指标与不同调参预算下报告结果，
读者难以判断某方法是否真正更优。本文提出并执行一套**预注册去噪基准**——判据、配置、种子与评估面板

以及跨方法**互补性度量**（M1 误差正交性 / M2 局部互补 / M3 频带互补）与**预注册的配对选择规则**。
**本文的第一贡献是基准与互补性度量学本身**；在此基础上按预注册规则实现的时频加权融合，
作为**条件性评估**如实报告。

在本文数据、本配对与本规则下，融合**未被任何最差单法击败、亦无崩溃（三态判定为状态 B）**，
但**未超越最优固定单法**：主配对融合 ΔSNR 中位 **0.0588 dB**，低于 `svd_lowrank`（**0.9482 dB**）
与 `fk_filter`（**0.9320 dB**）；预注册的次优对照融合达 **2.5295 dB**，高于全部五种固定单法；

## 3. 互补性度量

### 3.1 定义（预注册，先于任何融合结果）

| 度量 | 定义 | 值域 |
| :--- | :--- | :--- |
| **M1 误差正交性** | `O_ij = 1 − |⟨e_i,e_j⟩| / (‖e_i‖‖e_j‖)` | [0,1] |
| **M2 局部互补** | 窗级 `Lsig` 差超出该对池化 IQR×1.5 的窗占比 | [0,1] |
| **M3 频带互补** | 5 频带归一化误差谱的 base-2 JS 散度 | [0,1] |

### 3.2 ⚠️ M1/M2 分歧（**如实呈现，不得择优**）

- **M2 严重零膨胀**：10 对中 **8 对全局中位 = 0.000**；
- 按预注册规则（M2 优先）选定的主配对 **`fx_deconv × wavelet_threshold`**（M2 = 0.500000），
  但其 **M1 = 0.093807 为全 10 对最低**（误差近共线，内积 ≈ 0.906）；
- 而 M2 第二名 `fx_deconv × svd_lowrank`（M2 = 0.200000）
  **M1 = 0.575710 明显更高**；
- **结论**：**M1 与 M2 指向不同配对**。选择**绑定 M2**（预注册规则），**不改选**；
  该分歧本身是**发现**：M1 预测了融合增益，M2 没有（见 §4.3）。

### 3.3 M2 的样本与分层局限

- 分层 M2 为**小样本分数**（`n_obs` 45–135）；
- 分层值**高度不均匀**：主配对 M2 在 `model=M1` 层与 `noise=N3` 层均为 **0.0000**，
  而在 `M1_N1` 层达 **1.0000**；
- ⇒ **M2 的证据强度依赖模型与噪声类型**，不可跨层外推。

## 4. 融合评估（**预注册规则；主结论为负结果**）

### 4.1 规则与硬约束

- 权重 `w_i = C_i²`（方法**自身输出**的横向相干度）；鉴别分 `s_i = clip(0.4d + 0.3b + 0.3a, 0, 1)`；
  `w_i′ = w_i(1 − γ s_i)`（γ ∈ {0.4, 0.5, 0.6}）；**逐系数归一化**重建；
- **硬约束**：`fuse(y_i, y_j, params)` **签名不含真值**，AST 守卫禁导入真值生成器；
- **「一致 ≠ 正确」失效模式**：`w` **不含跨方法比较**、`s` **只做减权**、一致性子分**仅占 0.3** ⇒
  三机制在**数学上**阻止「两方法一致」兑换信任。

### 4.2 结果（**主配对 = 负结果；次优对照 = 正结果。主次不换**）

| 项 | ΔSNR（中位） | Lsig（中位） |
| :--- | ---: | ---: |
| **融合（主配对，γ=0.5）** | **0.0588 dB** | 0.020640 |
| **融合（次优对照，γ=0.5）** | **2.5295 dB** | 0.018103 |
| **逐观测 oracle（上界）** | **6.7033 dB** | （逐观测取最优，非可达基线）|
| 单法 `fk_filter` | 0.9320 dB | 0.009706 |
| 单法 `fx_deconv` | 0.0000 dB | 0.029151 |
| 单法 `wavelet_threshold` | 0.0422 dB | 0.015129 |
| 单法 `ssa_decomposition` | 0.2101 dB | 0.045928 |
| 单法 `svd_lowrank` | 0.9482 dB | 0.011218 |

**① 主配对（预注册规则选定）未击败任何固定单法**：融合 ΔSNR 中位 **0.0588** dB，低于 `svd_lowrank`（0.9482）与 `fk_filter`（0.9320）。

**② 次优对照（预注册的稳健性对照）击败全部固定单法**：融合 ΔSNR 中位 **2.5295** dB，高于全部 5 个单法。**该结果与①并列报告，不做主次调换。**

### 4.3 ⚠️ oracle 是**上界**，不是可达基线

「逐观测 oracle」= 在每个观测上选取 ΔSNR 最高的单方法。其宏平均 **6.7033 dB** **必然 ≥ 任何固定方法的逐观测最优**，且**逐观测需要真值** ⇒ **现实中不可实现**。
它与「固定配对融合」的**本质区别**：

- **固定配对**：一次选定，全观测通用（**可部署**）；
- **oracle**：逐观测按真值择优选法（**不可部署，仅为上界**）。

⇒ 论文**不得**把融合与 oracle 的差距表述为「融合失败」，而应表述为
「**融合未达到不可达上界**，且主配对未超越最优固定单法」——两者是不同的陈述。

### 4.4 γ 档的实测无效（**如实报告的设计发现**）

三档 γ 在主配对上的宏平均**四位小数完全相同**（0.0588 / 0.020640）。
**根因（诊断）**：`d` 子分因 `v_lo = 100 m/s` 远低于实际视速度而**恒为 0**；`b` 由带宽决定、两方法近似相等；
`a` 为**对称定义** ⇒ `s_i ≈ s_j` ⇒ `w′ = w(1−γs)` 在**逐系数归一化中近似约掉**。
⇒ **γ 档未构成**对「过平滑激励」失效模式的有效对冲 —— **本文更正**了设计阶段「γ 即对冲」的假设。

## 7. 讨论

**与结论同口径**：本文的第一贡献是**预注册基准与互补性度量学**；融合是**条件性评估**。
其状态 B 结论（无伤害、未被最差单法击败、未超越最优固定单法）**不改变**研究方案与数据协议 ——
基准与互补性度量学的方法学贡献**独立于**融合结果的强弱。

**适用边界（必须声明）**：上述融合结论仅在**本数据**（54 配置 / 270 观测；3 个冻结野外面板）、
**本配对**（由 M2 预注册规则选定）与**本规则**（`configs/fusion-rules.yaml`，tag `fusion-rules-frozen`）
之下成立；次优对照的正结果同样受该边界约束。

**不得事后择优**：本结论**不得**被解读为「更换配对或更换融合规则即可取得增益」——
配对与规则均在**看结果之前**预注册；任何事后更换都属事后选择（post-hoc），
**不再具备预注册证据力**，因而**不构成**对本文结论的补救。

**度量学层面的发现**：M1 与 M2 在**同一批数据**上对融合增益的预测力**不一致**
（M1 预测到增益、M2 未预测到）。该分歧在预注册规则下被**如实保留**（选择绑定 M2、不改选），
并作为**互补性度量的预测力差异**记录（post-hoc 标注）。

## 8. 结论

1. **第一贡献：预注册基准 + 互补性度量学**。判据、配置、种子与面板在**看方法输出之前**冻结；
   互补性度量与配对选择规则同样预注册 ⇒ **主配对的选择不含事后选优**。
2. **融合为条件性评估（状态 B）**：在本文边界内，融合**未被最差单法击败、亦无崩溃**，
   但**未超越最优固定单法**（主配对融合 ΔSNR 中位 **0.0588 dB** < `svd_lowrank` **0.9482 dB**）。
3. **主次不换**：预注册的**次优对照**融合达 **2.5295 dB**，高于全部五种固定单法；
   该正结果与第 2 条的负结果**并列报告**，不做主次调换。
4. **oracle 上界 ≠ 可达基线**：逐观测 oracle **6.7033 dB** 需要真值、**不可部署**；
   与它的差距**不得**表述为「融合失败」。
5. **M1 预测融合增益而 M2 没有**（post-hoc 探索，已标注）——该预测力差异本身是发现。
6. **判定结果**：**状态 B**（**判定人 = 用户（张涛）**；**判定时间 = 2026-09-28**）。
   **状态 A 不可主张**（适用边界见 §7，局限含义见 §9）。

3. **M2 零膨胀**（8/10 对中位为 0）与小样本分层分数 ⇒ M2 证据强度受限；
4. **DL 槽位空缺**：跨域 + 需改冻结环境（**不得**写成「未考虑」）；
5. **检索有界性**：有界滚雪球（非完整），且**初筛仅基于标题字段**；
6. **FP3 的 U 为部分分**（事件窗冻结时序缺口），**未回填**；
7. **`stats.py` 非幂等**：每次运行重写受版本管理的 `manifest.json`；
8. **融合负结果的适用边界**：本数据 / 本配对（M2 选定）/ 本规则下成立，
   **不得**外推为「融合方法普遍无效」；次优对照的正结果同样受该边界约束；
9. **oracle 非基线**：逐观测 oracle 需要真值，**不可部署**（见 §4.3）。

10. **三态判定为 B 的局限含义**：状态 B 意味着融合的贡献**降为条件性** ——
    「无伤害、未被最差单法击败」可在本文边界内主张，而**状态 A（融合有效 / 超越最优固定单法）不可主张**；
    因此本文的融合部分**不构成**对融合方法有效性的论证，其价值在于**预注册规则下的如实评估**。
