# 英译术语锁（P5.11 · 全稿唯一权威）

> 规则：**术语一律照此表**；表外新术语须先加入本表再用。数字来源以仓库产物为准，译文不得改动任何数字。

## 标题与元信息
| 中文 | 英文 |
| :--- | :--- |
| 预注册地震去噪基准与互补性分析：配对选择的失效诊断 | A Pre-Registered Benchmark and Complementarity Analysis of Seismic Denoising Methods: Diagnosing Selection Failure in Method Pairing |

## 句式与体裁（避免中文化英文）
| 中文习惯 | 英文 |
| :--- | :--- |
| 其一 / 其二 | First / Second |
| 如实报告 | reported as measured（**不用** truthfully/faithfully） |
| 未获益 | did not benefit |
| 劣于 / 优于 | is worse than / better than |
| 结论必须读作 | The result should be read as |
| 本文 | this study / this paper |

## 禁用词（不得进入英文稿）
`本批` `本轮` `此处更正` `修订史` `治理` `须写明` `不夸大` `删循环论证` `表述升级` `排查`
—— 即中文稿的读者形态词表，英文稿同样清零。
