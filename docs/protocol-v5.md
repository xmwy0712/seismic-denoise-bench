## 最终方案

V5唯一方案：以《基于信息互补性分析的地震数据去噪基准与轻量融合方法》为暂定题目，在310美元总预算内完成一篇可投稿的地球物理论文。固定主贡献是可复现的去噪基准、信号保真评估框架及跨方法互补性发现；条件性方法贡献是无需训练、可在 CPU 运行的相干噪声感知时频融合元方法。融合实验结果只改变论文主张强度，不改变研究方案、数据协议和投稿目标。

一、目标与能力边界
用户已经明确同意将原先“独立发明一种可获取其他方法均无法获取之信息的全新去噪方法”，重定向为“以基准和互补性发现为固定主贡献，以融合元方法为条件性贡献”。该同意应连同以下方法边界写入《目标重定向确认记录》：融合主要重新组合各输入方法已经保留的互补信息；如果某段真实信号被所有输入方法共同删除，融合通常不能可靠恢复该信号，因此本研究不承诺恢复所有现有方法均未保留的信息，也不把融合描述成未经证明的信号并集。最终交付是完成投稿，不承诺录用或发表。

二、研究设计
复现4至6种跨类别代表性方法，覆盖滤波、变换阈值、分解、低秩和许可合格的预训练深度学习方法，并强制保留至少一种针对相干噪声的强基线，如 f-k 滤波或 F-X 反褶积。先在带真值合成数据上比较各方法保留和损失的信息，再依据经统计确认的互补性设计唯一的融合算法：把各方法输出转换到统一时频表示，完成采样、时移、相位和振幅校准；使用局部相干度产生初始权重；再由视倾角与线性度、频带分布、跨方法一致性构成的相干噪声鉴别分数修正权重；最后逐系数归一化加权重建。该方法无需训练，所有规则、阈值和参数在主实验前冻结。

三、数据与预注册实验范围
主合成模型由 Ricker 子波、水平层状速度模型的反射系数序列及褶积正演构成。噪声包括带限高斯随机噪声、指定视速度的线性相干干扰和具有明确速度—频率关系的频散面波；固定采样率、道数、子波主频、噪声强度档位及每个配置至少5个独立随机种子。第二合成模型不得仍是纯水平层状模型，至少包含倾斜同相轴、弯曲同相轴和一个简单断层或速度横向变化，以检验非理想可分场景。

一个“合成配置”定义为合成模型、噪声类型、噪声强度和参数档位的笛卡尔组合；一个观测单位为同一配置下的一个随机种子。主张锁定所用配置清单在步骤3结束时冻结。野外范围在查看方法标签结果前冻结为：一套许可合格公开数据中的3个代表性面板或时窗，以及融合保守度参数的标称值、标称值减20%和标称值加20%，共9个设置；“各设置”仅指这9个预注册设置，不得事后挑选。

四、核心指标与统一汇总规则

1. 合成数据的首要质量指标为输出 SNR 提升：ΔSNR=10log10(||s||²/||y-s||²)-10log10(||s||²/||x-s||²)，其中 s 为真值、x 为含噪输入、y 为去噪输出，越高越好。
2. 唯一首要信号泄漏指标为真值事件窗归一化重建误差 Lsig=||M(y-s)||²/||Ms||²，越低越好；M 由干净真值按固定阈值生成后膨胀一个子波长度，生成规则在运行方法前冻结。噪声道中的信号投影、逐样本误差、振幅误差和局部相似度仅作解释性辅助指标，不参与三态判定。
3. 相干噪声抑制指标为 CNA=10log10(||nc||²/||PC(y-s)||²)，越高越好。nc 为已知注入的相干噪声，PC 是向预先由注入线性干扰和频散面波模板构成之子空间的最小二乘投影；实现必须先用纯相干噪声数据验证投影回收误差不超过5%。
4. 事件级指标预注册为真值事件窗内包络峰值到时绝对误差和归一化窗内能量误差。只有自动事件匹配在人工生成的已知事件测试集上达到至少95%正确匹配率时，才报告复杂的逐事件匹配指标；否则复杂匹配仅作辅助，核心事件证据固定使用真值窗到时和能量误差，不改变首要指标。
5. 每个方法先在每个配置内对种子求均值，再对全部配置等权宏平均，防止配置包含的种子数影响权重。方法比较使用同配置、同种子的配对差值；主检验采用双侧配对置换检验，显著性水平0.05，并对同一首要指标下与全部单法的比较使用 Holm 校正；同时报告配置分层自助法95%置信区间。首要指标缺失不得用删除不利配置的方式处理。

五、第11周三态主张校准规则
三态只校准论文中融合贡献的强度，不形成多套研究方案。状态在第11周末按以下唯一规则锁定：

1. 状态 A：融合同时满足四项条件。其一，ΔSNR 宏平均显著高于每一种单法，Holm 校正后 p<0.05，且所有配对差值95%置信区间下限大于0 dB；其二，Lsig 宏平均显著低于每一种单法，校正后 p<0.05，且“单法 Lsig 减融合 Lsig”的95%置信区间下限大于0；其三，CNA 相对 CNA 最高的单法之差的95%置信区间下限不低于-0.5 dB；其四，任何单个合成配置均不得出现ΔSNR 比该配置最差单法低超过0.5 dB，或 Lsig 比该配置最差单法高超过10%的实质性伤害。满足 A 时，融合列为与基准并列的主贡献。
2. 状态 B：不满足 A，但达到稳定运行标准，且不满足状态 C。稳定运行定义为全部预注册输入均返回形状正确的有限数值结果，无崩溃、NaN 或 Inf，异常幅值裁剪样本比例低于0.1%，单个面板 CPU 运行时间不超过全部单法运行时间总和的3倍；同时融合在ΔSNR 和 Lsig 两项宏平均上均未被最差单法显著击败。状态 B 下，固定主贡献仍是基准和互补性，融合作为受限应用示例如实报告。
3. 状态 C：出现以下任一情形即成立：超过5%的预注册输入无法产生有效结果；融合的ΔSNR 和 Lsig 宏平均同时被相应最差单法显著击败；或相干噪声鉴别模块失效。鉴别模块失效定义为：在具有系数级真值标签的相干噪声专项数据上，平衡准确率的配置宏平均低于0.60，或者加入该模块后相较未修正权重的融合使 CNA 下降超过1 dB 且该现象发生于至少一半相干噪声配置。状态 C 下，融合不作为正文方法贡献，正文仅保留基准与互补性结果，失败实现和原因记录在附录。
4. 第11周末若仅因计算尚未完成而不能判定，可顺延最多1周并立即删除一个预注册的次要噪声强度档位；顺延期满仍未完成时按状态 B 组织正文，但未完成的融合结果只能放入附录，且不得宣称已达到 B 的性能门槛。锁定后不得通过更换指标、配置或基线升级状态；唯一允许的变更是状态 A 依照野外规则单向降级为 B。

六、野外无真值评估与冲突裁决
野外数据使用四项冻结指标：①振幅保持，计算预选事件窗内稳健包络 RMS 相对原始数据的对数偏差，越接近0越好；②频谱残差，计算被移除数据在预注册信号频带内的能量占比，越低越好；③同相轴连续性，使用与融合权重不同实现的结构张量沿局部倾角计算连续性增益，越高越好；④差异剖面结构化盲评，隐藏方法标签并随机排列图像，用户间隔至少7天完成两次独立评分，按“残差是否含连续同相轴、是否含振铃、是否有局部振幅突变、噪声是否充分降低”四项0至2分清单计分，取两次均值并报告一致率。

无真值泄漏代理 LP 定义为：差异剖面在预选事件窗中、沿原始数据稳定事件倾角的结构相干能量，除以原始数据同窗结构相干能量，越低越好。事件窗和倾角只依据原始数据冻结，不依据任何去噪结果选择。LP 与融合使用的局部相干度不得采用同一代码或同一参数族。

四项指标先按9个设置中全部单法与原始数据形成的冻结尺度转换为方向一致的稳健 z 分数，再按振幅保持30%、频谱残差25%、同相轴连续性25%、盲评20%计算综合分 U；指标发生冲突时只按 U 裁决，不进行人工重新加权。状态 A 仅在以下条件全部满足时保留：融合的 U 宏平均不低于最佳单法，配置分层自助法95%置信区间下限不低于-0.10；融合 LP 相对 LP 最低单法的增幅不超过10%，其95%置信区间上限不超过15%；9个设置中均不存在 U 比最差单法低超过0.50或 LP 比最差单法高超过20%的实质性伤害。任一条件不满足即 A 单向降为 B。状态 B 和 C 不得因野外结果升级。

七、物理合理性、复现与开放规范
合成数据验收采用可复核标准：Ricker 主频由频谱峰值回算，误差不超过设定值的5%；线性干扰视速度由 f-k 峰值回算，误差不超过10%；频散曲线在预注册频率采样点的速度中位相对误差不超过10%；无噪声正演输出与独立参考脚本的归一化均方误差不超过10^-6。每种移植方法至少在一个作者示例或公开参考案例上完成定量比对：在相同参数下，输出归一化均方差不超过5%，或公开论文核心指标的相对误差不超过10%。达不到时不得进入正式基准。

* 执行能力风险：用户可能无法独立发现代码或地球物理实现错误。缓解措施是第1周能力实测、参考案例定量比对、单元测试和参数回算验收；未通过的模块不得进入正式实验。

* 鉴别指标过拟合风险：相干噪声模块可能只适用于水平模型。缓解措施是强制使用包含倾斜、弯曲同相轴和简单构造的第二模型，并以冻结的专项真值标签评价。
* 融合对齐风险：不同方法可能引入时移、相位翻转、振幅缩放或采样差异，逐系数融合会产生伪影。缓解措施是在融合前检测互相关时移、解析信号相位差、稳健振幅比例和采样网格；只按冻结规则完成重采样、整数或分数延迟校正、全局相位旋转和稳健增益标定，校正参数全部留痕。
* 野外循环论证风险：无真值指标可能与融合权重同源。缓解措施是 LP 和连续性采用独立结构张量实现，禁止与融合局部相干度共享代码和参数，并由四项固定权重综合裁决。
* 定性验收偏差风险：单人且缺乏专业背景可能误读差异剖面。缓解措施是隐藏标签、随机排序、间隔7天重复评分、使用固定四项清单并报告一致率；定性结果只占综合分20%。

* 许可证风险：移植源码、权重或数据可能禁止修改或再分发。缓解措施是逐项记录许可证、修改义务与兼容性；不允许再分发时仅发布下载脚本和校验值，许可不明确的材料不进入最终仓库。
