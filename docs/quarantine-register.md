## 常设规则（即刻生效，来源：P0.3-Am1 裁定 2）

1. **不可信输入原则**：任何**非 openclaw 写入**的代码 / 配置 / 数据，一律视为**不可信输入**：
   **不得 commit、不得执行、不得作为实现依据**。
2. **处置三步**：发现后立即 **停机报告 + 隔离 + 登记**，不得静默处理、不得"顺手采纳"。
3. **权威文本**：规范文本（任务单）的权威版本**仅**为 `docs/task-sheets/` 归档件
   （以 `MANIFEST.md` 哈希为准），其他位置的副本不具权威性。
4. **重复出现即升级**：**若隔离后同类文件再次出现**，不再静默重复隔离，
   **立即升级报告用户**（重复出现是更强的信号）。
5. **低风险 ≠ 可采用**：安全扫描结论为"低风险"**不构成**采用依据；
   许可不明 / 来源不明即不得入库（协议第七节）。

**规则 6 · "从零重写 / 不得参考"类要求的机械判据**

今后凡任务单出现"不得参考""从零重写""独立实现"类要求，一律以下述**纯代码层**指标为验收判据：

| 指标 | 阈值 | 说明 |
| :--- | :--- | :--- |
| 纯代码层 20-gram 覆盖率 | **≤ 2%** | 以被比对物（隔离件/参考件）的 20-gram 集合为基准 |
| 纯代码层最长公共串 LCS | **≤ 20 token** | 允许的 20 token 上限用于容纳**规格强制签名** |

- **计量口径**（必须随交付一并说明）：token 化规则（用 Python `tokenize`）、
  是否剥离注释与字符串（**须剥离**，得"纯代码层"）、n-gram 的 n（20）。
- **执行层义务**：交付时**自测并报数**（前后两组数值）。
- **签发方义务**：以**签发方脚本**为准复核；口径差异导致的小幅不一致属正常，
  但 **LCS 应完全一致**（本执行方两次独立复测的 LCS 均与签发方一致）。

**规则 7 · MANIFEST 更新必须全量校验**

1. **签发方义务**：每次更新 MANIFEST（新增/修正行），须对**清单全部行**执行
   全量校验（**字节数 + SHA256**，长度须为 64 位，大小写不敏感），并输出校验结果。
2. **执行层权利**：可**要求签发方提供校验输出**；执行层自身**仍须独立复跑**全量校验。
3. **执行层义务（不变）**：发现任一不一致 → **停机报告**，不得按推断执行，
   **不得自行更正产物或清单**。
4. **本规则由来（留档）**：2026-09-25 `P0.3-Am3` 声明哈希为 63 位（漏 1 字符），

## 收集守卫规则（P0.4-Am1 裁定 1，替代 Am1 裁定 3 的过粗表述）

> 本节记录 `tests/` 目录的收集守卫规则。**不使用代码内豁免名单**——
> 豁免写在代码里会被逐步掏空；清单文件才是可审计、可 diff 的载体。

1. **真绿守卫（核心）**：`tests/` 下任何**定义了顶层 `def test_*` 或 `class Test*`**
   的 `.py`，**必须**命名为 `test_*.py`，否则 fail。
   依据：假绿的根因是"定义了测试却不被收集"，此条直接针对该根因。
2. **清单守卫**：`tests/` 下**不定义测试**的 `.py`，必须或为 `conftest.py`，
   或登记在显式清单 `tests/_auxiliary.tsv`（格式：`文件名<TAB>用途<TAB>被谁导入`）。
   清单增删行须在 `docs/execution-log.md` 记一行。
3. **收集计数守卫**：`run_tests.ps1` 输出的 collected 数须与本批 execution-log 记录一致。
