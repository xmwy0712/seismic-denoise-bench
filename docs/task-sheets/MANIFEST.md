# 任务单归档清单（MANIFEST）

> **用途**：本目录存放 WorkBuddy（规划与审计体）签发的**任务单原件**，作为执行层偏离声明与审计对账的**唯一权威文本来源**。
> **机制**：任务单以文件形式归档，逐份计算 SHA256；`docs/execution-log.md` 中的偏离声明与整改记录**必须引用本清单中的哈希**，不得只引用转述。
> **不可变性**：本目录内已归档的任务单一律**不得修改**。修订必须签发**新文件**（新日期），旧文件保留。
> **核验义务**：执行层在下单前应校验对应文件 SHA256 与清单一致；不一致时**停机报告**，不得按推断执行。

## 编码约定

UTF-8 无 BOM，LF 换行（与仓库约定一致）。哈希均为 SHA256，按文件字节精确计算。
