任务：

4. 实现 src/bench/data/ricker.py：
   def ricker(f_main: float, dt: float, n: int) -> np.ndarray
   要求：n 取奇数；时域峰位于中心采样；归一化峰值振幅 1.0。
5. tests/test_ricker.py 最小测试：
   a) 峰值位置（中心采样）与归一化（峰值振幅 = 1.0）断言；
   b) 频谱峰值回算：f_main ∈ {15, 25, 40} Hz，dt = 0.002 s，n = 101，
      取 FFT 模峰对应频率，与 f_main 相对误差 ≤5%。
      实现要求：FFT 零填充至 ≥65536 点（否则 df≈5 Hz、量化误差可达 20%，
      会造成假失败），并对峰邻域做抛物线插值取亚 bin 精度；
      test 中固定随机种子（本测试实际不需要随机数，若引入必须固定种子）。
6. execution-log 记录：环境创建、依赖安装清单、测试文件、pytest 完整输出、
   三个主频的**实测误差数值**（不得只写"通过"）。

交付物：requirements.lock、src/bench/data/ricker.py、tests/test_ricker.py、
        pytest 完整输出文本、Makefile 或 run_tests.sh。
验收门：pytest 全绿；三个主频回算误差的实测值逐个写入 execution-log；
