任务
────────────────────────────────────────

1. `src/bench/data/synthetic.py`（最小版，仅本单范围）
   - `reflectivity(n_layers, rng)` → 水平层状反射系数序列（rng 为显式注入的随机源）
   - `forward(reflectivity, wavelet)` → 褶积合成无噪剖面，形状 `(n_samples, n_traces)`
   - `add_band_limited_noise(s, rng, band)` → 带限高斯随机噪声叠加
   - `add_linear_coherent(s, v_app, dt, dx, rng)` → 指定视速度的线性相干干扰
   - 频散面波、第二合成模型、噪声强度档位、配置矩阵 → **留给 P1 完整版**，本单不实现
   - 随机性一律通过显式 `rng` 注入（禁止模块级隐式全局种子），以便 P1 逐配置固定种子

2. `tests/ref_forward.py` —— **独立参考实现**
   用**不同的数值路径**实现同一正演（建议：频域乘积褶积，与时域直接褶积相对），
   并断言两者归一化均方误差 `NMS <= 1e-6`。
   **硬要求**：`ref_forward.py` 与 `synthetic.py` **不得共享任何实现代码**
   （WorkBuddy 将 diff 两文件；发现复制改名的，本单判不通过）。

3. `tests/test_data_acceptance.py`（**命名必须匹配 pytest 默认收集 `test_*.py`**）
   a) **Ricker 主频回算 ≤ 5%**：沿用 P0.2 的测量口径（零填充 ≥65536 点 + 峰值邻域抛物线插值），
      纳入正式验收；对 f_main ∈ {15, 25, 40} Hz 各测一次；
   b) **线性干扰视速度回算 ≤ 10%**：生成已知视速度的线性干扰 → 2D f-k 谱能量峰 `(f, k)`
      → 回算 `v = f / k`；**至少三档视速度**各测一次。
      实现须写明坐标与单位约定（`dx` 米、`dt` 秒、`k` 周/米），并**避开空间/时间混叠区**
      （选择 `v_app` 使干扰落在无混叠范围内；若某档落入混叠须在日志说明并改档）；
   c) **无噪正演双实现 NMS ≤ 1e-6**（即时域直接褶积 vs 频域乘积褶积）。

4. execution-log
   - 记录全部动作与**实测数值**（不得只写"通过"）：三个主频的回算误差、三档视速度的回算
     视速度与相对误差、双实现 NMS 实测值；
   - 记录本批 `pytest -q` 的 **collected 用例数**（P0.3-Am1 裁定 3 的防"假绿"要求）。
