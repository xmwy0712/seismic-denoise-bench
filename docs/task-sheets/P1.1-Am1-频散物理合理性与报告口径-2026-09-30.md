════════════════════════════════════════════
F1（须整改）· 解析频散式的默认值不物理 + 验收 c 存在"自证"风险
════════════════════════════════════════════

**事实（签发方实测）**：`dispersion_velocity` 在**默认参数**下（linear, v0=300, c=900）给出

    f= 5 Hz → 4800 m/s ; f=25 Hz → 22800 m/s ; f=40 Hz → 36300 m/s

即 v(f) = v0 + c·f 在默认参数下产生 **4.8–36.3 km/s** 的"面波"——**超地幔量级**。
**已注册配置是合理的**（`v_model: linear, v0: 500, c: 10` → 550–900 m/s），故本批数据无问题。

**风险（这是要整改的理由）**：验收 c 是**"估计值 vs 同一解析式"**——**自洽即可通过**，
无法发现解析式本身不物理。未来任何一次"忘了传参"的调用都会**静默**生成 36 km/s 的面波，
而验收 c 仍会通过。对一个以"可复现 + 物理可信"为卖点的基准，这属于**必须堵死的自证通道**。

**整改**

1. **R15-a · 验收 c 增加物理合理性断言**
   在预注册探测频带上，**解析 v(f) 必须落在配置中显式声明的物理区间内**。
   - 该区间写入 `configs/config_matrix.yaml`（建议键 `dispersion_v_band_mps: [100, 3000]`，
     具体上下限由你按浅层面波合理性提出，P1.5 冻结）；
   - 断言失败 = 配置不物理 → **fail**（不得只警告）。
   效果：c 从"自洽检验"升级为"自洽 + 物理"双重检验。

2. **R15-b · 消除静默默认值**
   `v_model` 相关参数（`v0` / `c` / `a` / `b`）当前有默认值，可被静默误用。
   **二选一**（推荐前者）：
   - **(i)** 改为**必填**（移除默认值，或设为 keyword-only 且无默认），调用方必须显式传参；
   - **(ii)** 保留默认值，但在 docstring 与模块头**显著标注**"默认值仅为占位、物理上不成立，
     必须显式传参"，且**在函数体内**对"使用了默认值"的情形发出显式警告或直接 `raise`。
   **禁止**保持现状（可静默产生不物理数据）。

**验收**：交付须给出 ① 新断言在"物理区间内/外"两种情形下的实测结果（后者须确实 fail，
可临时改参数演示后复原）；② 采取的 (i) 或 (ii) 方案的代码位置；③ 重跑 pytest 全文（含 collected 数）。
