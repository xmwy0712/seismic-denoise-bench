第二节 · 🔴 阻断项 F-CNA · 子空间张不住注入噪声（须知：这会让 CNA 变成死指标）
════════════════════════════════════════════

**签发方独立实测（自建测试，未复用你的验收）**

用**同族但不同实现**的噪声去测子空间回收误差（这才是实用情形——每个种子、每个观测的噪声都是**新实现**）：

| 情形 | 回收误差 | 门禁 5% |
| :--- | ---: | :--- |
| 精确模板回投（退化，你报的就是这一档） | ~1e-15 | ✅ |
| 线性干扰·同视速度·**换随机源** | **0.0000%** | ✅ |
| 线性干扰·同视速度·**换主频（22 Hz）** | **45.5492%** | ❌ |
| 频散面波·同参数·**换随机实现** | **98.4326%** | ❌ |
| 混合噪声（相干+随机） | **99.0040%** | ❌ |

**连"多堆实现"也救不回来（我实测）**：频散面波子空间用 k 个实现建基，另一个新实现的回收误差为

    k=1 → 98.76% ; k=5 → 92.80% ; k=10 → 81.90% ; k=20 → 71.90% ; k=40 → 38.45%（10 个新实现中位 39.1%、最大 51.0%）

频散面波由 `n_components` 个随机相位分量合成，是**高维家族**，抽样建基**不收敛**。

**根因（诊断已确定）**
你的先决验证测的是**退化情形**——被测噪声就是（或直接取自）建基用的模板本身，因此必然 ~1e-15。
而**真实注入噪声是家族的随机实现**：子空间只张住了"那几个具体波形"，
没张住家族的自由维度（面波的随机相位组合、线性干扰的主频）。
→ **投影回收几乎为零 ⇒ 所有方法的 CNA ≈ 0 dB ⇒ CNA 无区分度。**

**为什么这是阻断级（不是"小瑕疵"）**
三态判定依赖 CNA：状态 A 判据三（"CNA 相对 CNA 最高单法之差 CI 下限 ≥ −0.5 dB"）、
状态 C 判据三（"加入鉴别模块后 CNA 下降 >1 dB"）**都以 CNA 有效为前提**。
CNA 若恒为 ~0 dB，这两条判据既不能触发也不能排除——**三态机器会立在死指标上**。
必须在 P2 之前修好（本单完成即可，P1.5 冻结时把修正后的建基规则冻结）。

**整改要求（R16-a ~ R16-d）**

**R16-a · 子空间改为"张成注入家族"，而非"抽样建基"**
（推荐）由生成器**导出注入所用的分量基**：为每次相干噪声注入返回其**分量波形集合**
（线性干扰：按注册 `v_app` 与 `f_main` 的波形；频散面波：`n_components` 个**单分量**波形），
子空间直接由该分量基构造。理由：注入 = 分量基的线性组合 ⇒ 基**精确张成**家族。
（次选，若无法导出分量基）按注册配置构造**单参数模板集**：
每个注册 `v_app` × 每个注册 `f_main` 一个线性模板；频散面波按预注册探测频率各取单频分量模板。
**不得**再用"抽 N 个随机实现"的方式（已实测不收敛）。

**R16-b · 先决门禁改为"非退化"口径**
门禁数据必须是**独立新实现**（新建随机源，**不得**是建基所用的任何实现），
且按**三个族分别 + 混合**报告回收误差：线性干扰 / 频散面波 / 混合；阈值仍为协议值 **5%**。
**必须同时报告**：同一测试在"精确模板"下的误差（作为退化对照，说明二者差异）。
整改后预期：家族被精确张成时，独立新实现的误差应≈机器精度（≤1e-10）；
若仍显著大于 0，须说明残余未张成维度。
