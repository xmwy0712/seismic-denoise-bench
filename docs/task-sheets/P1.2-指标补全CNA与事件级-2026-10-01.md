════════════════════════════════════════════
一、CNA（相干噪声抑制指标）
════════════════════════════════════════════

协议定义：`CNA = 10*log10( ||nc||^2 / ||P_C(y - s)||^2 )`，**越高越好**。
其中 `nc` 为**已知注入的相干噪声**，`P_C` 是向**预先由注入线性干扰与频散面波模板构成之子空间**的
**最小二乘投影**。

实现要求
1. 子空间构造方式必须**写明**（例如：模板 Gram 矩阵 + SVD 截断 / 正交基构造 / 正则化最小二乘），
   并说明**截断阈值或秩选择规则**——该阈值是**冻结参数**（P1.5 冻结），本步给出候选值并声明语义。
2. 数值一律 float64；对非有限输入与空子空间须显式报错（不得返回 NaN/Inf 掩盖）。
3. **先决验证（硬门禁，协议明文）**：**先用纯相干噪声数据验证投影回收误差 ≤5%**。
   - 构造方式：`y - s = nc`（无随机噪声、无信号残留）→ `P_C(y-s)` 应几乎完全回收 `nc`；
   - 回收误差定义须写明（建议 `||P_C(nc) - nc|| / ||nc||`）；
   - **不达标即判定实现有 bug，不得进入主实验**（不得放宽容差、不得改判据）。
4. 验收还须覆盖：`y = s`（完全去噪）时 `P_C(0) = 0` → CNA 应为 `+inf` 或显式约定的哨兵值
   （沿用 C1–C6 的同类约定并**写明**）；`y = x`（不处理）时 CNA 应给出与"未抑制相干噪声"一致的量级。

════════════════════════════════════════════
二、事件级指标（预注册）
════════════════════════════════════════════

协议：真值事件窗内 (i) **包络峰值到时绝对误差**；(ii) **归一化窗内能量误差**。

1. 到时：对 `y` 与 `s` 各自取 Hilbert 解析信号包络，在**真值事件窗**内分别取包络峰值位置，
   到时误差 = 二者之差（绝对误差，单位 ms）；多事件时逐事件给出，并报告**中位数与最大值**。
2. 归一化窗内能量误差：`|E_y - E_s| / E_s`（窗内能量），逐事件给出并报中位与最大。
3. **与 Lsig 掩码的关系须写明**：事件窗来源为已冻结掩码规则（沿时间轴膨胀 n_T、half-up），
   本单**不得修改**该规则；若本单需要"事件表"（事件中心/时间/道范围），
   须落为**草案**并在 P1.5 冻结。

════════════════════════════════════════════
三、自动事件匹配器（含 95% 预注册门限）
════════════════════════════════════════════

1. 实现一个匹配器：把 `y` 中检出的事件与真值事件表配对（匹配判据须写明：时间容差、道号容差等）。
2. **门限（协议明文）**：在**人工生成的已知事件测试集**上须达 **≥95% 正确匹配率**。
   - 测试集须**人工可验证**（事件数、位置、分离度已知，含近邻/重叠等困难情形）；
   - "正确匹配率"定义须写明（精确率 / 召回率 / F1，建议同时报告三者）；
   - **未达 95%** → 复杂逐事件匹配**只能作为辅助指标**，核心事件证据**固定使用真值窗的
     到时与能量误差**（这是协议规定的降级路径，按此执行，不得自行放宽门限）。
