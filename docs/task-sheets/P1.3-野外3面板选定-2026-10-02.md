════════════════════════════════════════════
二、任务
════════════════════════════════════════════

1. **选定 3 个代表性面板/时窗**（"面板" = 道范围 × 时间窗的组合）：
   - **覆盖两个测区**（建议 2 个来自 MV、1 个来自 NAN，或反之——取决于数据质量，须给理由）；
   - 选择理由须**基于原始数据特征**（如：直达波/面波能量是否清晰、反射同相轴可辨性、
     区间内几何完整性、异常道或坏道是否过多），并写明你检查了哪些原始量（不许只写"看起来不错"）；
   - **优先包含相干噪声明显的区间**（地滚波/水中波/线性干扰），因本研究主题为相干噪声与互补性——
     但该优先级须作为**事前判据**写明，不得依据任何处理后结果反向挑选。
2. 每个面板落盘：
   - 道范围（起止道号）、时间窗（起止采样点或 ms）、测区标识；
   - 预览图（`docs/figures/p1_field_panel_{1,2,3}.png`，含坐标轴单位）；
   - 该面板内的**事件窗与倾角**（仅由原始数据导出；倾角用与融合权重无关的独立实现，
     写法与 P1.1 验收 f 项同源要求一致）。
3. 草拟**融合保守度 3 档参数的标称值**（标称 / −20% / +20% 三档），并说明"保守度"的语义
   （例如：抑制越保守 → 越接近输入）。正式冻结在 P1.5。
4. **CC BY 4.0 署名文本**必须随数据说明落盘（`docs/` 下数据说明节或 `license-register.csv` 引用），
   文本沿用已登记版本：Dugan, B. (2023) … Zenodo. https://doi.org/10.5281/zenodo.10407771 — CC BY 4.0。
