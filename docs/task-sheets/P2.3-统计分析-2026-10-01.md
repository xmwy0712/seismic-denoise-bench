| :--- | :--- |

| 多重校正 | **Holm**（族定义：**每个指标 × 每个分层内的 10 个方法对**为一个族） |

| 分层 | 全局 + 模型(M1/M2) + 噪声(N1/N2/N3) + 档位(L1/L2/L3) + 主频(15/25/40) + **模型×噪声** |

| 宏平均 | 逐方法对 270 观测的中位数与均值 + 自助 CI |

**纪律**：以上参数**先写入 `results/stats/preregistration.md` 再运行统计**；
跑完不得换检验类型、不得增删分层、不得改 B——任何"换个检验就显著"都是 P 值操纵。
