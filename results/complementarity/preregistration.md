## 1. 符号

对每个观测 (config_id, seed)：

- `s` = **干净真值**（冻结配置重放）
- `y_i` = 方法 `i` 的输出（`results/<config>_<seed>_<i>.npy`）
- `e_i = y_i − s` = 方法 `i` 的**误差**
- `M` = 冻结语义的**真值事件掩码**：`event_mask(s, f_main, dt, threshold = 0.5·max|s|)`
  （阈值规则见 `frozen-v2.item_06`；膨胀沿时间轴，锚点 `left = n_T//2`）
- `n_T` = 该观测的膨胀长度（`frozen-v2.item_06.n_T_per_config`；half-up 规则）
  ⇒ f_main = 15 / 25 / 40 Hz 时 **n_T = 33 / 20 / 13**

**方法集（5 个）**：`fk_filter` / `fx_deconv` / `wavelet_threshold` / `ssa_decomposition` /
`svd_lowrank` ⇒ 方法对 **C(5,2) = 10 对**。

## 2. M1 · 误差正交性指数（**必做，主度量之一**）

**逐观测**定义：

```
O_ij = 1 − |⟨e_i, e_j⟩| / (‖e_i‖₂ · ‖e_j‖₂)
```

- 全局正交 ⇒ `O = 1`；完全共线 ⇒ `O = 0`。
- **边界规则（预注册）**：若 `‖e_i‖₂ · ‖e_j‖₂ = 0`（某方法误差恒为零）⇒ 该观测该对记 `NA`，
  **不参与**中位聚合（不允许"完美方法"污染指数）。
- **值域**：`O ∈ [0, 1]`（柯西–施瓦茨保证）。
- **聚合**：逐观测 → **270 观测取中位数**（全局）；分层取**层内观测中位数**。

## 3. M2 · 局部互补指数（**必做**，呼应论文标题的"信息互补"）

### 3.1 窗格（**预注册定死**）

- **窗长** = 该观测的 `n_T`（逐观测，随 f_main 变化）；**步长** = `n_T // 2`（整数下取整）。
- 窗口起点 `t0 = 0, step, 2·step, …`，条件 **`t0 + n_T ≤ n_samples`**（**不截断**，避免边界伪影）。
- 窗口 `w` 覆盖时间样点区间 `[t0, t0 + n_T)`，**全道**（道方向不划分）。

### 3.2 窗级保真度（自由度 ①，**预注册定死**）

**采用「窗内 Lsig」**（与项目**冻结口径**一致；不另造定义）：

```
Lsig_w(i) = ‖M_w · (y_i − s)‖₂ / ‖M_w · s‖₂
```

其中 `M_w = M` 在窗口 `w` 内的限制（**照冻结掩码语义**，不做任何新变换）。

> **选择理由（预注册时给出，不留事后解释空间）**：
> ① Lsig 是本项目**已冻结的**唯一首要信号泄漏指标（`metrics-spec`），沿用可避免引入新定义；
> ② 裁定 D 已明确「核心事件证据 = **真值窗**指标」——窗级 Lsig 正是该口径的窗口化；
> ③ 另一候选「1 − 归一化误差」会**引入新定义**并需额外的截断/下界规则，不如前者干净。

**可评估性（预注册）**：窗口 `w` **可评估**当且仅当 `‖M_w · s‖₂ > 0`
（窗内无真值事件 ⇒ 保真度无定义）。不可评估窗口**排除**出分母。

### 3.3 互补判据（自由度 ②，**预注册定死**）

对方法对 `(i, j)`，定义窗级差值：

```
d_w = Lsig_w(i) − Lsig_w(j)
```

- **阈值池**：把该对的 `d_w` **在全部 270 观测的全部可评估窗口上汇总**为 `D_ij`。
  （**池化，非逐观测** ⇒ 阈值是该对的**固定常数**，排除逐观测挑阈值的空间。）
- **IQR 判据（预注册；倍数 1.5 = Tukey 惯用值）**：

```
T_ij = 1.5 × IQR(D_ij)
窗口 w 判为「互补」 ⟺ |d_w| > T_ij
```

- **语义**：该窗内**一方显著好、另一方显著失手**（差值的绝对量超出该对典型散布的 1.5 倍四分位距）
  —— 这是「融合能获益」的**直接证据**。
- **M2 值**：逐观测的 **互补窗占比** = `#互补窗 / #可评估窗`；
  若某观测**可评估窗 = 0** ⇒ 记 `NA`，不参与中位聚合。
- **值域**：`M2 ∈ [0, 1]`。
- **聚合**：逐观测 → **270 观测取中位数**（全局）；分层取**层内观测中位数**。
  **注**：阈值 `T_ij` **始终为全局池化值**，分层只影响**聚合**、不影响**阈值**（预注册）。

## 4. M3 · 频带互补（**可选，本单决定做；与 M1/M2 同时预注册**）

### 4.1 频带（**预注册定死**，取自冻结锚点）

以冻结频率锚点划分 5 个频带（Hz）：

| 频带 | 区间 | 冻结依据 |
| :--- | :--- | :--- |
| B1 | `[0, 5)` | 低于 `item_05.frequency_band_hz` 下限 |
| B2 | `[5, 15)` | 面波频带下段（5 → 首个主频档 15） |
| B3 | `[15, 25)` | 面波频带上段（15 → `f_hi = 25`） |
| B4 | `[25, 40)` | 含主频档 40 |
| B5 | `[40, Nyquist=250)` | `item_04` N1 频带上限 80 之上至 Nyquist |

### 4.2 定义

- 逐观测、逐方法：对误差 `e_i` 沿**时间轴**做 FFT，**在道方向求和**能量 ⇒ 一维误差功率谱；
  按上表把谱能量归入 B1..B5 ⇒ 得 5 维**归一化**分布 `p_i`（各带能量 / 总能量）。
- **JS 散度（base-2）**：

```
M3_ij = JSD(p_i ‖ p_j) = ½·KL(p_i‖m) + ½·KL(p_j‖m),  m = (p_i + p_j)/2
```

- **值域**：base-2 下 `JSD ∈ [0, 1]` ⇒ **`M3 ∈ [0, 1]`**。
- **边界规则**：若某方法总误差能量 = 0 ⇒ 记 `NA`。
- **聚合**：逐观测 → 270 观测中位数；分层取层内中位数。
- **定位**：M3 为**加分项**，**不参与**第二节的配对选择（预注册）。

## 5. 融合配对选择规则（**本单预注册，P3.2 执行**）

### 5.1 防循环约束（**硬**）

配对选择**只能基于单方法误差的互补性度量**（M1 / M2 / M3），
**不得基于任何融合输出** —— P3.2 之前融合输出**不存在**，这正是本单先于 P3.2 的意义。

### 5.2 规则（**机械、可重放**）

1. **主判据**：**全局 M2 中位数最高**的方法对；
2. **并列判据**：若 M2 并列（按中位数第 6 位有效数字比较），取 **M1 更高**者；
3. **再并列**：若仍并列，取**方法名按字典序较小者**（确定性兜底，防事后挑选）；
4. **稳健性检验（仅报告，不改变选择）**：该配对在 **模型×噪声** 6 个分层中，
   有多少层的 M2 中位数仍为全对最高 ⇒ 报告**一致性比例**（`x/6`）；
   **分层仅作描述**，**不得**据此改选；
5. **固定单一配对**进入 P3.2。**禁止多配对并行挑选**（那等于在配对维度调参）。
   若论文需要，**P3.2 可预注册一个"次优配对"作稳健性对照**，但**主结论绑定单一配对**。
