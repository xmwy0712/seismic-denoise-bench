## 2. ⚠️ 失效模式预答：**「两方法输出高度相似 ≠ 两者都正确」**

### 2.1 陷阱的精确表述

P3.1 的强制披露已证：主配对的 **M1 = 0.093807（全 10 对最低）** ⇒ **两方法误差近共线**
（`‖e_i‖·‖e_j‖` 归一化后内积绝对值 ≈ 0.906）。在**共线误差**下：

> 若把 **跨方法一致性/局部相似度** 用作 **权重正项**，则「两方法错在同一处」会被误读为
> 「两方法在该处都可信」⇒ **一致性虚高 → 权重虚高 → 融合固化了共同错误**。

**这就是"一致即正确"陷阱**，且在本主配对上是**高危而非理论风险**（M1 最低正是其度量）。

### 2.2 本设计的规避机制（**结构性，非靠调参**）

**机制 ①：w 的定义**中**完全不出现跨方法比较**。
`w_i` 只由**方法 i 自身输出**的**横向（跨道）相干度**给出（见 §3.1）。
⇒ 两方法是否一致，**在数学上无法抬高 `w`** —— 陷阱的燃料被从 w 里移除。

**机制 ②：跨方法一致性只出现在 `s` 中，而 `s` 只做"减权"。**
`s` 进入的公式是 `w′ = w·(1 − γ·s)`（冻结 item_10 语义），**s 只是抑制系数**。
⇒ **一致性再高，也只能让权重变小、绝不让权重变大**。
即「两方法一致」在本设计中**从不兑换信任**，最多导致**双方一起被抑制**
（进而退化为等权平均，见 §4.3）—— 这正是保守方向。

**机制 ③：s 的主项是"噪声结构"而非"一致性"。**
s 的三个子分中，**视倾角与线性度**（w_d）与**频带分布**（w_b）**合计 0.7**，
**跨方法一致性**（w_a）**仅 0.3** ⇒ 一致性**无法单独**把 s 推高（须配合结构证据）。

### 2.3 残余风险（**预注册承认，不声称解决**）

若两方法**把同一段信号一起删除**，且**剩余输出在结构上看起来正常**（高横向相干、低倾角、
落在信号频带），则 `w` 高、`s` 低 ⇒ **融合会保留该共同删除**，`Lsig` 因此**不会改善**。

> **本预注册不承诺解决该情形**；它由 §6 的 `Lsig` 指标**如实暴露**（若融合 `Lsig` 不优于
> 最优单法，即为该风险的实证）。**不得**在结论中把该风险表述为"未观察到"。

### 2.4 失效模式 #2：**过平滑激励**（条件 1，2026-10-06 补）

**机制**：`w_i = C_i²` 以**输出自身的横向相干度**为基础。
**过平滑的输出**（同相轴被抹平、能量扩散）在道方向上反而**更"连续"**
⇒ `C_i` 偏高 ⇒ **`w` 系统性向过平滑的方法倾斜**。

**这是与 §2.1 相反方向的偏置**：§2.1 的陷阱让**共同错误**获得信任（已被三机制关死）；
本失效模式让**过度平滑**获得信任（**不关死**，靠下述手段探测）。

**探测手段（预注册，不得事后更换）**：

| 手段 | 指标 | 判读 |
| :--- | :--- | :--- |
| 泄漏 | **`Lsig`**（唯一首要泄漏指标） | 融合 `Lsig` **相对单方法恶化** ⇒ 提示过平滑（信号被抹） |
| 事件级 | **事件窗内能量误差**（真值窗口径，裁定 D） | 事件能量被压低 ⇒ 与过平滑一致 |

**判据（预先声明，避免事后解释）**：

> **若融合的 `Lsig` 相对单方法恶化、而 `ΔSNR` 同时改善**，
> 即为**过平滑激励的实证**，**必须如实报告** —— 不得只报 `ΔSNR` 的改善而隐去 `Lsig` 的恶化。

**处置**：**不要求改设计** —— 三档 `γ`（0.4 / 0.5 / 0.6）正是**对冲**：
`γ` 越大，`s` 的减权越强 ⇒ 越保守。**三档全部报告**即该对冲的可见证据。

**残余风险（承认）**：若三档 `γ` **一致地**表现出 `Lsig` 恶化 + `ΔSNR` 改善，
则该失效模式**未被 γ 对冲掉**，须在论文中作为**设计局限**如实陈述。

## 3. 定义（**本单定死**）

### 3.1 `w` · 局部保真度权重（**逐方法、逐时频系数、横向度量**）

**时频表示**：对每条道沿时间做 STFT —— 窗长 = 该观测 `n_T`（冻结 item_06，15/25/40 Hz ⇒
33/20/13），跳步 = `n_T // 2`，**Hann 锥形**，
**重叠相加**（OLA）。得到 `Y_i(τ, f, j)`（τ 窗序号、f 频率、j 道号）。

**横向相干度**（"局部相干度"，协议第 18 行用词）：

```
C_i(τ, f, j) = |Σ_{j′∈N(j)} Y_i(τ, f, j′) · conj(Y_i(τ, f, j′+1))|
               / ( Σ_{j′∈N(j)} |Y_i(τ, f, j′)|² · Σ_{j′∈N(j)} |Y_i(τ, f, j′+1)|² )^{1/2}
```

- `N(j)` = 道 `j` 的**固定邻域**：`N(j) = {j−1, j, j+1} ∩ [0, n_traces−1]`（预注册）。
- 语义：方法 i 的输出在该时频点**沿道方向是否连续**（信号同相轴横向连续 ⇒ 高）。
- **只用到方法 i 自己的输出** ⇒ **与两方法是否一致无关**（机制 ①）。

**权重**：

```
w_i = (C_i)^p ,  p = 2（预注册）
```

（`p = 2` 使横向相干性的差异被放大，但**不引入跨方法信息**。）
边界：`C_i < 0` 不可能（绝对值）；若分母为 0 ⇒ `w_i = 0`。

### 3.2 `s` · 相干噪声鉴别置信度 ∈ [0, 1]（**逐方法、逐时频系数**）

三个子分（**各 ∈ [0,1]**），权重**预注册固定**：

| 子分 | 权重 | 定义 |
| :--- | ---: | :--- |
| `d_i` 视倾角与线性度 | **0.4** | 由该窗的 2D 谱（幅度）取**能量峰** → 视速度 `v_app = f/|k|`；若 `v_app < v_band` 下限（`100.0` m/s）**或**线性度（峰值能量/总能量）> 0.5 ⇒ 判为低速线性干扰。映射到 [0,1]：`d = clip((v_lo − v_app)/v_lo, 0, 1)`（`v_app ≥ v_lo` 时为 0）。**只用方法 i 自己的输出**。|
| `b_i` 频带分布 | **0.3** | 该方法误差在**冻结频散带** `[5.0, 25.0]` Hz 内的能量占比（误差 = `y_i − x`，`x` = 含噪输入；**`x` 非真值**，允许）。`b = clip(占比, 0, 1)`。|
| `a_i` 跨方法一致性 | **0.3** | `a = 1 − |⟨Y_i, Y_j⟩| / (‖Y_i‖·‖Y_j‖)` 的**反向**：即局部相似度高 ⇒ `a` 高。**这是唯一用到另一方法的子分**。|

```
s_i = clip(0.4·d_i + 0.3·b_i + 0.3·a_i, 0, 1)
```

**机制 ③**：`a_i` 单独最大只能贡献 0.3 ⇒ **一致性无法单独把 s 推高**。
**机制 ②**：`s` 只以 `(1 − γ·s)` 形式**减权** ⇒ 一致性从不兑换信任。

> **`x` 的使用声明（条件 2，2026-10-06 补）**：
> **官方运行在 `params` 中传入 `x`；`x` 为共享输入、非真值**
> —— 所有方法共享同一含噪输入，故传入不违反「融合不得接触真值」的硬约束（§0.1）。
>
> **降级规则（预注册）**：任何一格 `x` 缺失 ⇒ `b_i = 0`，
> **且 `metrics.csv` 的对应行必须标注**（如 `x_missing: true`），**不得静默**。
> 官方运行的 `x` 由**冻结观测重放**得到（与 P2.2 全矩阵同源，`seed` 决定），
> 复现者可用同一 `seed` 重建。

### 3.3 合成（**冻结 item_10 语义，未改**）

```
w_i′ = w_i · (1 − γ · s_i)        γ ∈ {G['G_minus20'], G['G_nom'], G['G_plus20']}   （三档全报）
```

### 3.4 重建（**逐系数归一化 OLA**）

```
ν_i = w_i′ / (w_1′ + w_2′ + ε)          ε = 1e-12（仅防除零，不改变权重的相对关系）
y_fused(τ,f,j) = ν_1 · Y_1(τ,f,j) + ν_2 · Y_2(τ,f,j)
```

- **逐系数归一化**（协议第 18 行"逐系数归一化加权重建"）：**每个 (τ,f,j) 各自归一到 1**。
- **窗拼接**：逆 STFT 后按 **Hann 窗重叠相加**；逐样点除以**该样点的窗函数累计和**
  （Hann 的 OLA 归一化，即 `Σ_k w(n − kH)²` 的对应形式）⇒ 消除窗边缘幅度起伏。

**退化规则（预注册，防未定义行为）**：

| 情形 | 处理 |
| :--- | :--- |
| `w_1′ + w_2′ ≤ 0`（双方均被完全抑制） | **退化为等权**：`ν_1 = ν_2 = 0.5`（保守，不引入未定义行为） |
| `w_1′ + w_2′ > 0` | 按上式归一化 |
| 某系数只有一方非零 | 该系数**完全取该方**（归一化自然给出） |

> **§4.3 的语义**：双方**都**被显著抑制时，融合退化为**平均** ——
> 即"两方法一致 **且** 结构像相干噪声" ⇒ **不获得额外信任**，只得到平均。**保守方向正确。**
