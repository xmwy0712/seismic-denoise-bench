## 2. 比较对象（**定死，3 个**）

对**每个** `(config_id, seed, γ)` 单元，融合 `y_fused` 与下列**单方法**比较：

| # | 对照 | 说明 |
| ---: | :--- | :--- |
| 1 | **方法 i** | 主/次优配对的第一个方法（主配对 `fx_deconv`；次优 `fx_deconv`） |
| 2 | **方法 j** | 配对的第二个方法（主配对 `wavelet_threshold`；次优 `svd_lowrank`） |
| 3 | **最优单法（per-observation）** | 该观测上 **ΔSNR 最高**的单方法（5 法中择优，**逐观测**决定，用**单方法指标**不接触真值以外信息） |

> **配对单位**：同一 `(config_id, seed, γ)` 内，融合 vs 各对照**一一配对**。

## 3. 检验（**定死**）

| 参数 | 定值 |
| :--- | :--- |
| 检验 | **配对置换检验（符号翻转）**，**双侧** |
| 置换次数 | **B = 10,000** |
| 显著性 | **α = 0.05** |
| 统计量 | 配对差**均值** |
| 多重校正 | **Holm**（族 = **每个「指标 × 配对角色 × γ 档」内的 3 个比较对象**） |
| 效应量 | 配对差**中位数** |
| 置信区间 | **分层自助 95% CI**（percentile），**B = 10,000** |
| 分层 | 全局 + 模型(2) + 噪声(3) + γ 档(3) = **9 个分层键** |

## 4. 指标（**定死，5 个**）

`ΔSNR` / `Lsig` / `CNA`（**仅 N2/N3**，N1 ⇒ NA）/ 事件到时中位 / 事件能量中位。

## 5. 报告纪律（**先声明**）

1. **三档 γ（0.4 / 0.5 / 0.6）全部报告**，含最差档；
2. **主结论绑定主配对**；次优对照**只作稳健性**；
3. **对比「最优单法」**（协议四态判定的基准）与对比配对内两方法，**均须报告**；
4. **post-hoc 探索**（M1 vs M2 谁更好预测融合增益）**显式标注**、**不进主结论**；
5. **条件 1 的失效模式 #2 探测**：若**融合 `Lsig` 相对单方法恶化、而 `ΔSNR` 改善**，
   即为**过平滑激励的实证**，**必须如实报告**（不得只报 `ΔSNR`）。
