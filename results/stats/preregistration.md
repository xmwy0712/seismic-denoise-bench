## 2. 配对与检验（**定死**）

| 参数 | 定值 |
| :--- | :--- |
| **配对单位** | 同一 `(config_id, seed)` 内的方法**两两配对** |
| **对数** | C(5,2) = **10** 对 |
| **检验** | **配对置换检验**（**符号翻转**，sign-flip），**双侧** |
| **置换次数** | **B = 10,000** |
| **显著性水平** | **α = 0.05** |
| **统计量** | 配对差的**均值**（符号翻转检验的标准统计量） |
| **多重校正** | **Holm**（逐步向下） |
| **校正族定义** | **每个「指标 × 分层」内的 10 个方法对** 为一个族 |
| **效应量** | 配对差的**中位数** |
| **置信区间** | **分层自助 95% CI**，**B = 10,000**（percentile 法，第 2.5 / 97.5 百分位） |
