# P4.2 · 三态判定输入缺口补全 · **补算预注册补充件**

> **性质**：本件在**任何补算之前**落盘。
> **何谓"补算"**：从**已存在的产物**（`results/metrics.csv`、`results/fusion/metrics.csv`）
> 计算此前**遗漏的对照**，**不运行任何新实验**、**不产生任何新数据**。
> **为何需要**：P4 的 `docs/three-state-inputs.md` 因**统计预注册未含「vs-最差单法」对照**，
> 把 B-5/B-6/C-2 记为「无法判定」—— 这是**判定输入缺口**，须补全（属**补充输入**，
> **不是**事后改判据，也**不是**改预注册的检验族）。

----

## 1. 补算的**理由**（先声明，防"事后选择检验"之嫌）

- **缺口来源**：P3.2 统计预注册件（`results/fusion/stats_preregistration.md`）定义的比较对象为
  `vs_method_i` / `vs_method_j` / `vs_best_single`（**3 个**），**不含最差单法**；
- **协议要求**：状态 B 的判据 ⑤⑥ 与状态 C 的判据 ② 均以「**被最差单法显著击败**」为条件
  （`protocol-v5.md` 第 37–38 行）；
- ⇒ **补算的是协议已要求、而统计预注册遗漏的对照**，属**补齐输入**，非新增检验族。

## 2. 方向纪律（**成文** —— A-4 教训）

> **「最差单法」的极值方向随指标方向翻转。**
>
> | 指标 | 方向 | 「最差」= |
> | :--- | :--- | :--- |
> | `ΔSNR` | **越高越好** | **`min`** |
> | `Lsig` | **越低越好** | **`max`** |
> | `CNA` | 越高越好 | `min` |
>
> **A-4 教训（P4 已发生）**：首版对 Lsig 误用 `min`（取到最**好**单法），
> 违规数 **虚报为 231**，修正后 **24**。**该错误若未被核查，数字将直接进论文。**
> 本件把该纪律**成文**，作为后续一切「最差/最好单法」运算的前置约定。

## 3. 补算范围与口径（定死）

| 项 | 定义 |
| :--- | :--- |
| **配对单位** | 同一 `(config_id, seed)`（**270 对**） |
| **融合** | 主配对 `fx_deconv × wavelet_threshold`，**γ = 0.5**（三档全报另见 P3.2） |
| **对照** | **最差单法** —— 按**宏平均**在该指标上最差者（ΔSNR 取 `min`、Lsig 取 `max`） |
| **检验** | **配对符号翻转置换**，**双侧**，**B = 10,000** |
| **显著性** | **α = 0.05** |
| **多重校正** | **Holm**（族 = **本补算的 2 个对照**，即 `ΔSNR vs 最差` 与 `Lsig vs 最差`） |
| **效应量** | 配对差中位数 |
| **CI** | **分层自助 95%**（percentile），**B = 10,000** |
| **随机种子** | 置换 **20261010** / 自助 **20261011**（与 P3.2 统计**同种子**，保持一致性） |
| **"显著击败"的判定** | `融合` 相对最差单法：ΔSNR 显著更低、或 Lsig 显著更高，**且方向不利于融合** |

## 4. 判定规则（**先声明**）

| 状态 | 判据 | 本补算给出 |
| :--- | :--- | :--- |
| **B-5** | 融合 ΔSNR **未被**最差单法**显著**击败 | `p_holm` 与效应量方向 |
| **B-6** | 融合 Lsig **未被**最差单法**显著**击败 | 同上 |
| **C-2** | 融合 ΔSNR 与 Lsig **同时**被最差单法显著击败 | B-5 ∧ B-6 同时「被击败」 |

## 5. 不在本件范围（**定格为不可判定**）

| 项 | 处置 |
| :--- | :--- |
| **C-3**（鉴别模块失效：平衡准确率 <0.60 或 CNA 下降 >1 dB） | 所需「系数级真值标签的相干噪声专项数据」**不存在**，冻结期内**不可生产** ⇒ **永久「无法判定」**，写入论文局限；**禁止事后造数据补测** |
| **B-3**（异常幅值裁剪比例 <0.1%） | `results/fusion/metrics.csv` **无任何裁剪/离群相关列** ⇒ **不可补算**，与 C-3 同等处理 |
| **B-4**（单面板 CPU 时间 ≤ 全部单法总和的 3 倍） | `wall_time_ms` **列存在但 1620 行全为空** ⇒ **不可补算**，与 C-3 同等处理 |
| **完整野外 9 设置** | FP3 依赖窗指标**维持 N/A**（裁定 F 保守处置不变）；**不得**回填全窗值 |
